Upload the BIN view export in whichever format you have it. The tool detects the format from the file extension.

Online-ൽ ഇത് നിർബന്ധമില്ല — BIN TRACES തന്നെ import ചെയ്യും. എങ്കിലും ഫയൽ ചേർത്താൽ ഓരോ BIN-ന്റെയും കൃത്യമായ തീയതി ഇവിടെ വരും, തുകകൾ SPARK-മായി ഒത്തുനോക്കും, Challan Mapping-ന് BIN തിരിച്ചുള്ള ഗൈഡും കിട്ടും. ചേർക്കുന്നെങ്കിൽ താഴത്തെ പട്ടികയിൽ തിരുത്തലുകൾ വരുത്തുന്നതിന് മുൻപ് ചേർക്കുക — ചേർത്താൽ പട്ടിക പുതുതായി ഉണ്ടാക്കും.

ഈ ഫയൽ എവിടെ നിന്ന് കിട്ടും?
TRACES login ചെയ്ത ശേഷം Menu bar-ലെ Challan Management → Check Challan/BIN Status ക്ലിക്ക് ചെയ്യുക. BIN സെലക്ട് ചെയ്ത് Proceed ചെയ്യുക. അടുത്ത പേജിൽ മാസം (calendar) സെലക്ട് ചെയ്ത്, BIN Status dropdown-ൽ Unclaimed എടുത്ത് Proceed ചെയ്താൽ BIN details (തുക ഉൾപ്പെടെ) കാണാം. താഴെ CSV, XLSX or PDF ആയി ഡൗൺലോഡ് ചെയ്യാം. — TRACES ലോഗിൻ

4 ReconciliationCheck the rows

Each BIN transfer voucher matched against SPARK's Annexure I totals for that month. Edit any cell if something looks off, then generate.

SPARK-ലെ TDS വരികൾ മാസം തിരിച്ച് താഴെ കാണാം — ഒരു മാസം TRACES-ലെ ഒരു BIN-ന് തുല്യം. ഓരോ വിഭാഗത്തിലെയും BIN date ആണ് ടെംപ്ലേറ്റിലെ മൂന്ന് തീയതി കോളങ്ങളിലും (payment, deduction, deposit) വരുന്നത്. ഏത് സെല്ലും തിരുത്താം; എല്ലാം ശരിയെങ്കിൽ ടെംപ്ലേറ്റ് ഉണ്ടാക്കുക.

SPARK-ൽ TDS ₹0 ഉള്ള ജീവനക്കാരെയും റിട്ടേണിൽ ഉൾപ്പെടുത്തണമെങ്കിൽ മാത്രം ഉപയോഗിക്കുക. ഓരോ വരിയും അതത് മാസത്തെ വിഭാഗത്തിൽ ചേരും; deduction / deposit തീയതികൾ ഉണ്ടാകില്ല. Online-ൽ ആകെ 200 വരി വരെ മാത്രമേ പറ്റൂ — അതിൽ കൂടുതൽ വരുമെങ്കിൽ Offline route ഉപയോഗിക്കുക. Only if you also want the employees SPARK lists with TDS ₹0 in the return. Each row goes into its own month's challan and is written without a date of deduction or deposit.

Challan Mapping guide

TRACES-ൽ Challan Mapping ചെയ്യുമ്പോൾ ഓരോ BIN-നും താഴെ പറയുന്ന Sl. No. വരികൾ ടിക് ചെയ്യുക; Difference (B−C) ₹0 ആകണം.

TRACES-ൽ ഇത് എങ്ങനെ upload ചെയ്യാം?
1. TRACES-ൽ TAN ഉപയോഗിച്ച് ലോഗിൻ ചെയ്യുക → e-file & View → File TDS/TCS Forms & Statements (പഴയ "Compliance under Income-tax Act, 1961" അല്ല).
2. Form No. 138 → File Now → Tax Year, Quarter, Regular, Prepare & File Online.
3. Deductor / Responsible Person വിവരങ്ങൾ പരിശോധിക്കുക.
4. Challan Details-ൽ unconsumed challans/BINs import ചെയ്യുക (BIN കൈകൊണ്ട് ചേർക്കാൻ പറ്റില്ല, import മാത്രം).
5. Annexure 1 → Add Bulk Deductee Details → Browse File (ഈ CSV) → Upload.
6. Challan Mapping: മുകളിലെ ഗൈഡ് പോലെ ഓരോ BIN-നും വരികൾ ടിക് ചെയ്യുക.
7. Validate Statement → തെറ്റുകൾ തിരുത്തുക → DSC / Aadhaar OTP / EVC PIN ഉപയോഗിച്ച് e-verify ചെയ്ത് acknowledgement സൂക്ഷിക്കുക.
ഇത് പൊതുവായ വിവരണമാണ്; portal-ൽ കാണുന്ന പേരുകൾ അനുസരിച്ച് ചെയ്യുക. Online statement-ന് 200 deductee records വരെയേ പറ്റൂ.
Everything above runs in this browser tab — files are read locally and nothing is uploaded anywhere. PDF/CSV/XLSX parsing libraries load once from a CDN, so the first run needs internet; the data itself never leaves your machine.
